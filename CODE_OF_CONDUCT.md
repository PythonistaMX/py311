# Código de Conducta

## Nuestro compromiso

En este proyecto promovemos un entorno abierto, respetuoso y colaborativo para aprender ingeniería y analítica de datos.

## Conducta esperada

- Tratar a todas las personas con respeto.
- Aceptar retroalimentación técnica con apertura.
- Priorizar claridad, rigor y colaboracion.
- Cuidar el lenguaje y evitar ataques personales.

## Conducta inaceptable

- Acoso, insultos o descalificaciones.
- Comentarios discriminatorios o lenguaje ofensivo.
- Publicación de información privada sin consentimiento.
- Cualquier conducta que afecte negativamente el ambiente de aprendizaje.

## Aplicación

Los mantenedores pueden moderar, editar o remover contenido que incumpla este código y, de ser necesario, restringir la participación en el repositorio.

## Reportes

Para reportar incidentes de conducta, contacta a los mantenedores del repositorio de forma privada; no uses un *issue* público, porque los *issues* de GitHub son visibles para todos.
